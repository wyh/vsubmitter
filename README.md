# vsubmitter - 多平台自媒体内容一键提交工作台

`vsubmitter` 是一款专为自媒体创作者打造的 Chrome 浏览器扩展（Manifest V3 标准）。告别狭窄拥挤的小弹窗，点击扩展图标即可直接在浏览器中打开**宽大舒适的独立控制台标签页**，支持一键将视频的 **标题、正文描述、话题标签及横/竖版封面** 自动同步填入四大主流创作者后台：

- 📕 **小红书** (`creator.xiaohongshu.com`)
- 🎵 **抖音** (`creator.douyin.com`)
- 📺 **微信视频号** (`channels.weixin.qq.com`)
- ⚡ **哔哩哔哩 (B站)** (`member.bilibili.com`)

---

## 🌟 升级特色（v1.1.0）

1. **独立宽屏工作台（告别弹窗易失焦、拖拽难的问题）**：
   - 点击工具栏插件图标，直接打开/激活一个全屏工作台网页（`dashboard/index.html`）。
   - 切换到 Finder 拖文件、截屏粘贴都不会导致面板关闭或数据丢失。
2. **大尺寸拖拽选区 & 智能剪贴板粘贴**：
   - 包含超宽大拖拽区，直接从桌面拖入 `.mp4` 视频和封面图片。
   - **支持 Cmd + V 任意处粘贴**：截屏后直接按 `Cmd + V`，工作台会根据图片长宽比，**自动判断并填入竖版封面或横版封面框**！
3. **横版与竖版双封面支持**：
   - 📱 **竖版封面 (3:4 / 9:16)**：专供小红书探索流、抖音竖屏推荐流、视频号主页。
   - 🖥️ **横版封面 (16:9)**：专供 B站标准封面、抖音横屏/PC 端、视频号横版卡片。
4. **Markdown 智能拆解与平台字数自动适配**：
   - 粘贴 Markdown 文本，自动识别并拆分成结构化表单：
     - **小红书**：严格限制 20 字，自动截取前 20 字。
     - **抖音**：限制 30 字，自动截取前 30 字。
     - **视频号**：智能生成 6~16 字短标题（推荐 15 字以内），过滤不支持的标点。
     - **B站**：标题上限 80 字，标签自动模拟回车键生成 Tag 气泡。
5. **人机协同安全闭环**：
   - 插件仅执行表单填写和素材注入体力活，各后台最终的**「发布/提交」按钮留给你亲自核对后点击**，零封号与风控风险。

## 🚀 重新加载与使用步骤

1. 打开 Chrome 扩展管理页：`chrome://extensions/`
2. 找到 `vsubmitter`，点击右下角 **「🔄 重新加载 (Reload)」** 图标。
3. 点击 Chrome 工具栏右上角的 `vsubmitter` 图标：
   - 立即打开全新的**全屏宽大工作台**！
4. 在左侧拖入视频文件、竖版/横版封面，或直接粘贴 Markdown 文案。
5. 点击右侧的 **「🚀 一键同步填入所选平台」**，查看实时控制台执行日志。
6. 切换到对应的 4 个后台标签页确认无误后，手动点击发布！

## 📂 项目文件结构

```
vsubmitter/
├── manifest.json              # Chrome MV3 配置文件（已绑定打开大屏工作台）
├── background/
│   └── service-worker.js     # 后台服务：管理标签页、点击图标打开大屏、执行脚本注入
├── dashboard/
│   ├── index.html            # 宽屏独立工作台主界面
│   ├── style.css             # 现代化大屏排版样式
│   └── app.js                # 工作台交互、Markdown 解析、图片比例识别与同步调度
├── scripts/
│   ├── dom-helpers.js        # DOM 与富文本操作辅助库
│   └── adapters/
│       ├── douyin.js         # 抖音平台适配器（支持横竖封面）
│       ├── bilibili.js       # B站平台适配器（横版封面、标签回车）
│       ├── wechat_channels.js# 微信视频号适配器（短标题过滤、横竖封面）
│       └── xiaohongshu.js    # 小红书平台适配器（严格20字截断、竖版封面）
├── icons/                    # 扩展图标 (16/32/48/128px)
└── README.md
```
